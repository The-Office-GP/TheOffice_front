# TheOffice - Frontend

##  Description

**TheOffice** est une application web connectée à l’API backend du même nom.  
Elle permet à un utilisateur de :

- S’inscrire et se connecter
- Créer et gérer une ou plusieurs entreprises
- Suivre son portefeuille
- Acheter des matières premières et des machines
- Recruter des salariés
- Visualiser des statistiques selon ses choix de production

---

## ️ Stack technique

- **Langage principal** : JavaScript (React)
- **Framework principal** : React

### Frameworks et bibliothèques complémentaires :

- `react-router` – pour la navigation entre les pages
- `Material UI` – composants UI stylisés
- `Axios` – gestion des appels API
- `Dexie` – stockage local (IndexedDB)
- `react-hook-form` – gestion avancée des formulaires
- `chart.js` – visualisation de données (statistiques)

---

## Architecture du projet

Le projet est organisé selon une architecture modulaire :

- `api/` – gestion des appels API vers le backend
- `components/` – tous les composants réutilisables
- `context/` – gestion des contextes (authentification, global state)
- `pages/` – pages principales de l’application
- `style/` – fichiers CSS (ou fichiers `.module.css` / `.scss` selon le setup)
